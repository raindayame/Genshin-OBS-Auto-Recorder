# Genshin-OBS-Auto-Recorder

這是一款專為《原神》玩家與創作者設計的全自動角色裝備展示錄影工具。
結合了 Tesseract OCR 影像辨識與 OBS WebSocket 技術，本工具能幫你自動掃描帳號內的所有角色、連動 OBS 進行自動錄影，並在結束後精準輸出一份「角色時間軸 (Timestamps)」，讓你無痛完成影片錄製與時間軸標記！

✨ 核心功能
自動辨識防呆：自動讀取角色名稱，繞完一圈自動停止，無需手動計算人數。

OBS 無縫連動：程式會自動控制 OBS 的「開始錄影」與「停止錄影」。

一鍵產出時間軸：錄影結束後自動生成 OBS_Timeline.txt，直接貼到 YouTube 資訊欄即可使用。

名單記憶功能：若已掃描過名單，下次可直接讀取快取跳過掃描，瞬間開始錄影。

📥 下載與安裝
⚠️ 請注意：不懂程式的玩家，請不要點擊綠色的 Code 下載原始碼！

請前往本頁面右側的 [Releases] 區塊。

找到最新的版本，下載附帶的 .zip 壓縮檔（懶人包內已包含免安裝版的 OCR 辨識引擎）。

將 ZIP 檔解壓縮到你的電腦中。

【極度重要】解壓縮的路徑請務必為「全英文」！
❌ 錯誤示範：C:\Users\User\桌面\原神錄影工具 (包含中文)
✅ 正確示範：C:\Genshin-Auto-Recorder

🛠️ 事前準備與設定
在執行程式之前，請務必確認以下遊戲與 OBS 設定已完成：

遊戲畫面設定：

將《原神》解析度設定為 1920x1080（視窗化或無邊框皆可）。

隊伍配置：

為了讓辨識順利啟動，請確保隊伍編排為：第一位「奇偶」、第二位「主角」、第三位「安柏」。

角色狀態確認：

請確認所有角色的「武器」與「聖遺物」皆已配置到你要展示的正確狀態。

OBS 設定與密碼取得：

確保 OBS 已開啟，並成功擷取到《原神》遊戲畫面。

在 OBS 上方選單點選：[工具] -> [WebSocket 伺服器設定]。

勾選 「啟用 WebSocket 伺服器」。

點擊 「顯示連線資訊」，並將裡面的「伺服器密碼」複製起來備用。

🚀 使用說明
進入《原神》遊戲，並打開角色介面。

雙擊執行資料夾內的 image_v2.exe。
(若系統跳出「使用者帳戶控制 (UAC)」請求管理員權限，請點選「是」，這是為了讓程式能正常對遊戲發送按鍵)

依照黑色命令提示字元視窗上的提示操作：

確認完畢後按下 Enter。

貼上剛剛複製的 OBS WebSocket 密碼並按下 Enter。

選擇是否讀取舊名單：

如果你是第一次使用，程式會自動開始「階段一」掃描所有角色。

如果資料夾內已有 characters_list.txt，程式會詢問是否跳過掃描 (y/n)，輸入 y 即可直接進入錄影階段。

放開雙手：

掃描結束後，程式會自動將角色切換回第一位，並啟動 OBS 錄影。

每個角色將停留展示 3 秒後自動切換下一位。

錄影完成：

腳本跑完後會自動通知 OBS 停止錄影，你可以在資料夾中找到熱騰騰的 OBS_Timeline.txt 時間軸檔案！

⚠️ 警告與常見問題 (FAQ)
Q: 程式跑到一半，我想緊急停止怎麼辦？

A: 請隨時按下鍵盤左上角的 Esc 鍵。程式偵測到後會安全中斷掃描或錄影，並自動將 OBS 錄影存檔。請絕對不要在遊戲內手動按 q 或其他按鍵干擾腳本。

Q: 為什麼程式一開始掃描就直接閃退或報錯？

A: 這通常是因為你把資料夾放在了名稱有「中文」的路徑下（例如：桌面、我的文件、下載），導致 Tesseract OCR 引擎無法讀取路徑。請將整個資料夾移到 C:\ 或 D:\ 底下的全英文資料夾中即可解決。

Q: 為什麼掃描時常常辨識錯誤或漏掉角色？

A: 請確認你的遊戲解析度嚴格設定為 1920x1080，這是因為影像裁切座標是基於此解析度設計的。

Q: 下載執行檔時，Windows 防毒軟體跳出警告？

A: 由於程式包含「模擬鍵盤滑鼠操作」的功能（為了自動切換角色），這類使用 PyInstaller 打包的自動化腳本偶爾會被 Windows Defender 誤判。本專案完全開源，若有疑慮可直接查看本頁面的 Python 原始碼，或自行安裝 Python 環境執行 .py 檔。
